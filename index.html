The Problem

Problem Statement

Build a basic e-commerce website using Flask (Python), HTML, and CSS.

Website should allow users to
  • Log in and log out
  • View a list of products
  • Add and remove items from a cart
Add simple AI features
  • Show product recommendations when items are added to the cart
  • Include a basic chatbot

The Solution

Open jeytex.online on your devices now!!!

Open jeytex.online in the browser on your phone or laptop for the live demo.

Recommendation Logic

AI-like Recommendations

We faked AI recommendations by storing predefined related products inside each item in our database, the recommendations list.

So instead of real AI
  1. When a user adds a product to the cart
  2. We simply read its recommendations field
  3. And display those items as AI recommendations

Extra Stuff

Extra Stuff (Deployment)

GitHub Workflow

We used GitHub to collaborate on the project.

  • One repo was shared with the team
  • Everyone cloned it and used pull to get latest changes
  • After coding, we committed (saved changes) and pushed (uploaded to GitHub)
  • This kept everyone’s work synced and up to date

Deployment

We connected the repo to Render, which automatically built and deployed our website. Every new push updated the live site.

Custom Domain

We Bought a Domain

We bought jeytex.com (for ₹98) and linked it to Render using DNS settings, making our project live on our own custom domain.
