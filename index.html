E-Commerce System

A modular web application for product browsing, cart management, recommendations, and deployment.

Watch Demo Explore Features

The Problem

A shopping app has to coordinate multiple user actions without confusing the customer: viewing products, remembering cart choices, suggesting useful items, and keeping access controlled.

The Solution

One clean Flask application that connects every shopping step.

Products load instantly, the cart stays active in the user session, and recommendations turn basic browsing into guided discovery.

  • Routes separate product, cart, login, and recommendation behavior.
  • Sessions preserve cart data while the user moves through the app.
  • Templates keep the interface reusable and easy to improve.
